# DOKO E-Commerce Website - Simple Viva Questions & Answers
**Duration: 5 Minutes | Team: Graduation Project**

---

## 1. DESIGN - Easy Questions About How It Looks

### Q1: Why did you choose green as the main color for DOKO?

**Answer**: "Our team chose green because it represents fresh food and makes people feel healthy. Green is perfect for a grocery store because it reminds customers of fresh vegetables and fruits."

### Q2: How does the website look different on phones vs computers?

**Answer**: "On phones, the menu becomes a simple hamburger menu to save space, and everything stacks vertically. On computers, we can show more things side by side like product grids and full navigation menus."

### Q3: What makes DOKO easy to use?

**Answer**: "DOKO is easy to use because:
- Big, clear buttons that are easy to click
- Simple navigation menu
- Pictures of all products
- Clear prices and descriptions
- Works well on phones and computers"

### Q4: How did you make the website load fast?

**Answer**: "We made the website fast by:
- Using smaller image files
- Loading images only when needed
- Using simple, clean code
- Optimizing the database queries"

---

## 2. PAGE - Easy Questions About Website Pages

### Q5: What is the most important page on your website?

**Answer**: "The homepage is most important because it's the first thing customers see. It shows our best products, tells about free delivery, and helps customers start shopping quickly."

### Q6: How does the search feature work?

**Answer**: "The search works like this:
- Customer types what they want (like 'apple')
- JavaScript sends the search to the server
- PHP searches the database for matching products
- Results show up instantly without reloading the page"

### Q7: How do customers create accounts and log in?

**Answer**: "Customers create accounts by:
1. Going to register.php page
2. Filling name, email, password
3. Clicking 'Register' button
4. System saves their information safely

To log in:
1. Go to login.php
2. Enter email and password
3. System checks if they match
4. If correct, they can access their account"

### Q8: What happens when customers add items to cart?

**Answer**: "When customers add to cart:
- JavaScript saves the item in browser storage
- Cart icon shows the number of items
- Customer can see all items in cart.php
- Total price updates automatically
- Items stay in cart even if they close browser"

---

## 3. CRUD - Easy Questions About Managing Data

### Q9: What does CRUD mean?

**Answer**: "CRUD means the four basic things you can do with data:
- **C**reate: Add new things (like new products)
- **R**ead: View or find information
- **U**pdate: Change existing information
- **D**elete: Remove things you don't need"

### Q10: How do you add new products to the store?

**Answer**: "To add new products:
1. Admin goes to admin panel
2. Clicks 'Add New Product'
3. Fills in: name, price, description, category
4. Uploads a product photo
5. Sets how many are in stock
6. Clicks 'Save' - product appears in store immediately"

### Q11: How do customers update their profile information?

**Answer**: "Customers update profiles by:
1. Going to profile.php page
2. Clicking on fields they want to change
3. Typing new information (name, email, address)
4. Uploading new profile picture if wanted
5. Clicking 'Save Changes'
6. System updates database with new information"

### Q12: What happens when you delete a product?

**Answer**: "When deleting a product:
1. Admin finds the product in the list
2. Clicks 'Delete' button
3. System asks 'Are you sure?' to prevent mistakes
4. If confirmed, product disappears from store
5. Old product photo is removed from server
6. Database record is safely deleted"

## 4. FINISH - Easy Questions About the Project

### Q13: What was the hardest part of building DOKO?

**Answer**: "The hardest part was making sure everything works together:
- Making sure cart data saves correctly
- Getting images to upload and display properly
- Making sure the website works on all devices
- Testing all the different features together

Our team learned a lot by solving these problems!"

### Q14: What would you add to DOKO if you had more time?

**Answer**: "If we had more time, we would add:
- Real-time chat for customer support
- Wishlist feature for saving favorite products
- Email notifications when orders are ready
- Better mobile app
- More payment options like credit cards"

### Q15: What did you learn from building this project?

**Answer**: "We learned many important things:
- How to build complete websites from start to finish
- How to make websites work on phones and computers
- How to keep customer data safe and secure
- How to solve problems when things don't work
- How to organize code so it's easy to maintain

Most importantly, we learned how real e-commerce websites work!"

## Very Simple Technical Terms (For Beginners):

### Design Terms:
- **Responsive**: "Website that works on phones, tablets, and computers"
- **Mobile-First**: "Designing for phones first, then making it better for bigger screens"
- **User Interface (UI)**: "How the website looks and feels to users"

### Page Terms:
- **Session**: "How the website remembers who you are while you browse"
- **AJAX**: "Technology that updates parts of the page without reloading everything"
- **Frontend**: "The part of the website you can see and interact with"

### CRUD Terms:
- **Database**: "Where all the website information is stored"
- **API**: "How different parts of the website talk to each other"
- **Backend**: "The behind-the-scenes code that makes everything work"

### General Terms:
- **PHP**: "Programming language that runs on the server"
- **MySQL**: "Database system that stores product and user information"
- **JavaScript**: "Programming language that makes websites interactive"

## Tips for Answering Questions:

### Be Natural:
- Use everyday words, not technical jargon
- Give examples from your actual website
- Show enthusiasm - talk about what you enjoyed building

### Be Specific:
- Mention actual pages (like "profile.php" or "checkout.php")
- Talk about real features you built
- Explain with examples ("Like when customers add apples to cart...")

### Be Honest:
- It's okay to say "That was challenging but we learned how to..."
- Talk about problems your team solved
- Share what you would do differently next time

### Practice Out Loud:
- Time yourself - aim for 30-45 seconds per answer
- Practice the easy questions first
- Smile and be confident!
