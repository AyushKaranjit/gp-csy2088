DOKO E-commerce Testing Command Reference
=======================================
Shell context: Windows PowerShell (pwsh). Adjust path separators for Linux/macOS as needed.
Project root for app code: websites/doko

1. Install / Update Dependencies
--------------------------------
# From repository root
cd websites/doko
php -v                # Verify PHP available (>=7.4)
composer install       # Install phpunit + mockery
composer dump-autoload # Regenerate autoloader if adding classes

2. Quick All Tests (Custom Lightweight Runner)
---------------------------------------------
# Does not require phpunit binary; uses tests/run-tests.php
php tests/run-tests.php

3. PHPUnit - All Suites (Default)
---------------------------------
# Uses tests/phpunit.xml (bootstrap + colors + suites)
# Composer script (preferred)
composer test
# Direct (vendor binary)
./vendor/bin/phpunit --configuration tests/phpunit.xml
# On Windows PowerShell alternative path form
dotnet  # (IGNORE: placeholder if pwsh warns about execution policy; remove this line)
php ./vendor/bin/phpunit --configuration tests/phpunit.xml

4. Individual Test Suites
-------------------------
# Unit tests only
composer test-unit
./vendor/bin/phpunit --configuration tests/phpunit.xml --testsuite Unit

# Integration tests only
composer test-integration
./vendor/bin/phpunit --configuration tests/phpunit.xml --testsuite Integration

# API tests only
composer test-api
./vendor/bin/phpunit --configuration tests/phpunit.xml --testsuite API

5. Single Test Class / File
---------------------------
# Directly execute a single test file via PHP (works for simple class-based tests)
php tests/Unit/AuthControllerTest.php

# Via phpunit selecting the class
./vendor/bin/phpunit --configuration tests/phpunit.xml tests/Unit/AuthControllerTest.php

6. Filter to Single Test Method
--------------------------------
# Use --filter with part or full method name (regex allowed)
./vendor/bin/phpunit --configuration tests/phpunit.xml --filter testUserCanLogin AuthControllerTest

7. Verbose Output
-----------------
composer test-verbose
./vendor/bin/phpunit --configuration tests/phpunit.xml --verbose

8. Code Coverage (HTML + Text)
------------------------------
# Generates coverage/ directory (ensure Xdebug or PCOV installed & enabled)
composer test-coverage
./vendor/bin/phpunit --configuration tests/phpunit.xml --coverage-html coverage/

# Open coverage report (Windows)
start .\coverage\index.html

9. Running Inside Docker Containers
-----------------------------------
# Start stack (from repo root)
docker compose up -d

# Run all tests (custom runner) inside php container
docker compose exec php bash -lc "cd /websites/doko && php tests/run-tests.php"

# Run phpunit all suites
docker compose exec php bash -lc "cd /websites/doko && ./vendor/bin/phpunit --configuration tests/phpunit.xml"

# Run a specific suite
docker compose exec php bash -lc "cd /websites/doko && ./vendor/bin/phpunit --configuration tests/phpunit.xml --testsuite Unit"

# Coverage inside container (ensure Xdebug installed in image)
docker compose exec php bash -lc "cd /websites/doko && ./vendor/bin/phpunit --configuration tests/phpunit.xml --coverage-html coverage/"

10. Maintenance / Troubleshooting
---------------------------------
# Re-generate autoload after adding/removing classes
composer dump-autoload -o

# Clear previous coverage report
Remove-Item -Recurse -Force .\coverage  # PowerShell
rm -rf coverage                         # Linux/macOS

# Verify phpunit version
./vendor/bin/phpunit --version

# Show defined composer scripts
composer scripts

11. Minimal Quick Loop Commands (Copy/Paste Friendly)
-----------------------------------------------------
# Full test run (fast) - custom
php tests/run-tests.php

# Full test run (phpunit)
./vendor/bin/phpunit -c tests/phpunit.xml

# Unit only
./vendor/bin/phpunit -c tests/phpunit.xml --testsuite Unit

# Single file
./vendor/bin/phpunit -c tests/phpunit.xml tests/Unit/AuthControllerTest.php

# Single test method
./vendor/bin/phpunit -c tests/phpunit.xml --filter testUserCanLogin AuthControllerTest

# Coverage
./vendor/bin/phpunit -c tests/phpunit.xml --coverage-html coverage/

12. Environment Notes
---------------------
- Tests assume a separate test database (see tests/bootstrap.php); ensure credentials match docker-compose or local setup.
- For consistent HTTP-related tests, CLI env sets HOST as localhost by default via configuration.
- If coverage reports fail, ensure Xdebug extension is enabled: php -m | Select-String -Pattern Xdebug

End of file.
